# 🚀 Featured Projects

## ⚡ Power and Area Optimized FFT Architecture Through Multiplier-Level Hardware Design

**Final Year Project**

A comparative FPGA-based study of different multiplier architectures integrated into an **8-point Radix-2 DIT FFT architecture**.

### Implemented Architectures

- Conventional / Basic FFT
- Vedic Multiplier based FFT
- Modified Booth Multiplier based FFT
- Wallace Tree Multiplier based FFT

### Work Includes

- RTL implementation using **VHDL/Verilog**
- Design of custom multiplier architectures
- FFT Butterfly architecture
- Testbench development
- Functional verification
- MATLAB reference-model comparison
- CSV-based RTL-to-MATLAB result analysis
- FPGA synthesis and implementation
- Comparison of **Power, Area and Performance**

🔗 **Repository:**
[Comparative Analysis of FFT Multiplier Architectures on FPGA](https://github.com/Swapnil-Varma/Comparative-Analysis-of-FFT-Multiplier-Architectures-on-FPGA)
